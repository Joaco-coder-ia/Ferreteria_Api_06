# EP1 — Frontend puro

Esta es la versión preparada específicamente para la Evaluación Parcial 1. Usa únicamente HTML5 semántico, una hoja CSS3 externa y JavaScript ES6+, sin backend, React ni base de datos.

## Ejecutar

Abre esta carpeta en Visual Studio Code, instala la extensión **Live Server** (`ritwickdey.LiveServer`) y presiona **Go Live** en la esquina inferior derecha. También puedes abrir `index.html` con cualquier servidor estático local.

## Incluye

- Inicio y catálogo con datos simulados desde el Excel.
- Búsqueda por nombre, marca y código.
- Filtro por categoría y disponibilidad.
- Detalle de producto.
- Carrito y confirmación simulada con retiro o despacho.
- Login, registro e historial local.
- Responsive para móvil, tablet y escritorio.
