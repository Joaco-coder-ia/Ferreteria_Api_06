# Ferretería Los Maestros — construcción paso a paso

Esta rama main es la base de aprendizaje del proyecto frontend de DSY1104. Aquí se incorporarán HTML, CSS, JavaScript y datos mediante ramas pequeñas, commits comprobables y pull requests reales.

## Regla principal

No copies el proyecto completo de una vez. Construye una función, pruébala con Live Server, explícala con tus propias palabras y recién entonces crea el commit.

## Respaldo

La solución terminada se conserva en la rama respaldo/version-completa. Esa rama sirve como referencia y no se debe modificar.

## Orden de construcción

1. Estructura HTML semántica.
2. Portada y catálogo estático.
3. Estilos y diseño adaptable.
4. Catálogo JSON y fetch.
5. Búsqueda, filtros y detalle.
6. Carrito y pedidos.
7. Acceso, registro y cuenta.
8. Persistencia, accesibilidad y documentación final.

Consulta docs/PLAN_APRENDIZAJE_GIT.md antes de comenzar.
